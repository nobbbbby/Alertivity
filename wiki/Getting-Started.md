# Getting started

## Choose a build

| Feature | App Store build | Source build (non-sandboxed) |
| --- | --- | --- |
| CPU, memory, disk, and network monitoring | Yes | Yes |
| System status and menu bar customization | Free | Yes |
| Custom system thresholds, notification cooldown, and high-activity duration | Pro; fixed defaults are free | Fully unlocked |
| Sustained critical activity notifications | Yes | Yes |
| High-activity process list and process notifications | Unavailable | Yes, when process sampling is available |
| Process detection thresholds, ignore rules, and process actions | Unavailable | Yes, when process sampling is available |

The source version requires **macOS 14 (Sonoma) or later**.

[Download from the Mac App Store](https://apps.apple.com/app/alertivity/id6756399719), or [build from source](https://github.com/nobbbbby/Alertivity/wiki/Developer-Guide) for process monitoring.

## First launch

1. Open Alertivity and find its indicator in the macOS menu bar.
2. The optional welcome guide previews the menu bar style. Choose **Use This** to save a previewed style; browsing styles alone does not change your preferences.
3. Choose **Set Up Notifications…** if you want alerts. macOS will ask for permission.
4. In the App Store build, the final step introduces Pro customization. Monitoring and notifications remain free with the default settings; purchases are available later in **Settings → Pro**.
5. Choose **Done**, **Skip for Now**, or close the guide. Monitoring continues either way.

Reopen the guide through **Help → Getting Started…**. Your preferences are kept. Unlike the style preview, the guide’s auto-switch toggle saves immediately.

## Everyday use

Open the menu bar indicator to inspect activity. Use [Settings](https://github.com/nobbbbby/Alertivity/wiki/Settings) to change the indicator, thresholds, or alerts. Preferences are saved locally.

The interface supports English, German, French, Japanese, and Simplified Chinese.
